# ADHD-friendly workstreams

The portal's ADHD-support improvements are implemented as one shared interaction model rather than isolated features:

1. **Focus Lane foundation** — one next action, smallest step, energy fit, completion, park/resume continuity.
2. **Focus Workbench** — a dedicated low-distraction execution route with 5/15/25/45-minute time boxes and a stuck path to Ready Room.
3. **Activation and decomposition** — Focus Lane links into Ready Room's existing `Help me start` and task decomposition flow.
4. **Attention management** — low-distraction mode, one dominant action, and explicit `Not now` handling keep optional information out of the active moment.
5. **Memory and recovery** — Focus Lane stores the current item and energy choice locally so a return visit can resume without reconstructing context.
6. **Cross-portal pass** — the shared component is used from Captain's Chair, inherits the Endeavour 27 visual system, remains keyboard-labelled, and is responsive at mobile widths.

The feature is supportive UX, not medical treatment or diagnosis. It should reduce friction without implying that every Captain has the same needs.
