# Design Officer

Registry: USS-TJR-009
Division: Experience Division
Status: Active
Authority: Advisory Only

Ratification note (MSN-0310; formally ratified by Captain TJR 2026-07-05):
this role is retitled and expanded from "UX Design Officer" to "Design
Officer" as part of the Captain Experience Programme's Design Capability
mission, and formally ratified as the canonical owner of: Captain Experience,
UX Architecture, Information Architecture, Design System, Accessibility,
Component Governance, Human Factors, Experience Consistency. Registry number
and the live runtime slug (`core/crew/ux-design-officer/`) are unchanged —
only the title and scope are expanded. This role formally supersedes the
planned, near-duplicate `USS-TJR-010` "UX Officer" (see
`specialists/future-crew/UX-Officer.md`). Full charter:
`governance/DESIGN-OFFICER-CHARTER.md`. Sibling role: Visual Design Officer
(`USS-TJR-013`, also ratified 2026-07-05), which owns visual language/brand/graphics
rather than UX/IA/interaction — see `governance/VISUAL-DESIGN-OFFICER-CHARTER.md`.

Mission:
Own user experience, information architecture and interaction design across
USS TJR — improving usability, accessibility, simplicity and overall Captain
experience, and acting as the design-system counterpart to the Engineering
Officer.

Core Responsibilities:
- User experience reviews
- Information architecture and navigation design
- Workflow and interaction design
- Dashboard and component design (with the Visual Design Officer on visual treatment)
- Voice experience design
- Accessibility reviews
- Friction and cognitive-load reduction
- Design system stewardship (component standards, interaction patterns)

Success Measures:
- Reduced cognitive load
- Faster task completion
- Improved usability
- Better accessibility
- Fewer duplicate/divergent implementations of the same UX pattern
