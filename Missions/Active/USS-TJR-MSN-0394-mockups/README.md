# Endeavour 27 — reference mockups

Source images for `USS-TJR-MSN-0394-endeavour-27-visual-system.md`'s §1 Design North Star
analysis. Referred to by number throughout that doc's §1.1–§1.8.

- **`image1-desktop-hub-readyroom-humansystems-briefs.png`** ("Image 1") — 4-panel desktop
  mockup: LifeOS Hub (Command view), Ready Room (Focus view), Human Systems (Focus/Insight
  view), Briefs (Read view). The original, first-shared reference set — §1.1 was built from
  this image directly.
- **`image2-responsive-grid-and-style-guide.webp`** ("Image 2") — 10-panel grid: the same 4
  surfaces at desktop + iPad landscape + iPad portrait + iPhone widths, plus a "Key Design
  Elements" panel giving named typography levels and component styles. §1.2 (mobile nav),
  §1.3 (typography/components), §1.4 (responsive layout) were built from this image.
- **`image3-like-for-like-redesigns.webp`** ("Image 3") — 7-panel grid labelled "Interface
  Concepts (Like-for-like redesigns)": Emergency Alerts, Shopping List, Technical OSINT,
  Health OSINT, a second Briefs treatment, Captain's Chair, and an iPhone Hub view — plus a
  footer legend with named hex values (Primary Navy/Command `#0B1E2E`, Surface Slate
  `#142B3D`, Accent TJR Blue `#3B82F6`, Sand Warm Accent `#D6B88C`). §1.5 (additional
  reference surfaces) and §1.6 (the two now-resolved discrepancies — Captain's Chair mode,
  Briefs tab structure) were built from this image.
