Purpose: Specialist retrieval registry -- the 5 build/engineering specialists that tools/supabase/collaboration_router.py and specialist_router.py route Advisory Board questions to (advisory-workbench's BoardView -> POST /api/advisory {action:"advice"}). Distinct from the 18-officer Advisory Board council, which is a separate, UI-only construct in lcars-portal/src/app/advisory-workbench/_components/shared.tsx and never touches this file. Built 2026-08-09 (Advisory Workbench UX review) -- this file never existed since the collaborative retrieval pipeline was first wired up, so every Board convene since then silently degraded (FileNotFoundError -> officer_perspectives always empty). "Allowed Types" mirrors the live specialist_permissions.allowed_document_types rows in Supabase exactly as of 2026-08-09 so this file and the DB agree; permission_allowed_types() intersects the two, so listing a type here the DB doesn't already allow is a silent no-op, never an escalation. Real document_type values seen in knowledge_documents: ADR, Architecture, Capability, Crew, Mission, Knowledge Base, Personal Archive.
