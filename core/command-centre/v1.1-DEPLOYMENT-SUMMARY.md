## Support

### Troubleshooting

**Dashboard doesn't load**
- Verify Dashy v4 running: `docker ps | grep dashy`
- Check port 8081 available: `netstat -an | grep 8081`
- Restart: `./control stop && ./control start control-deck`

**Links not working**
- Verify network connectivity to GitHub
- Check localhost services (Ollama, OpenClaw) running
- See CARD-LINK-AUDIT.md for full link inventory

**Configuration questions**
- See CONTROL-DECK-v1.1-REVIEW.md for detailed rationale
- See CONTROL-DECK-OPERATIONS.md for service details
