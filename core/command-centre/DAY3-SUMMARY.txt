 HOW TO USE

Setup (5 minutes):

  1. Start backend API:
     cd core/command-centre/backend
     npm start
     # Output: Server running on http://localhost:5000

     cd ../../core/coordination
     python3 number_one_exporter.py --export-sample

  3. Open dashboard:
     open core/command-centre/frontend/index.html
     # or navigate to: http://localhost:8000/...

  4. Verify widgets display live data:
     - All 4 widgets should show data
     - Each widget should show LIVE badge
     - Data should update every 45 seconds

  5. Test fallback behavior:
     - Stop backend (Ctrl+C)
     - Widgets should show FALLBACK badge
     - Mock data should still display

  6. Test manual refresh:
     - Click "🔄 Refresh Now" button
     - Widgets should refresh immediately

  7. Test debug mode:
     - Click "🐛 Debug" button
     - Console should appear in bottom-right
     - Shows refresh logs and timestamps

 KEY DESIGN DECISIONS
════════════════════════════════════════════════════════════════════════════════

✅ HTTP POLLING (not WebSockets)
   Rationale: Simple, sufficient for Phase 2, no new infrastructure
   Benefit: 45-second interval balances responsiveness and efficiency
   Future: Day 4 can upgrade to WebSockets for < 1s updates

✅ AUTO-REFRESH (default on, user can toggle)
   Rationale: Keeps dashboard current without manual intervention
   Benefit: Captain always sees latest data
   Future: Can make refresh interval user-configurable

✅ MOCK FALLBACK (always available)
   Rationale: Dashboard never shows "unavailable"
   Benefit: Graceful degradation when API down
   Implementation: Realistic mock data matches real structure

✅ DATA SOURCE INDICATORS (visible on every widget)
   Rationale: Transparency about data freshness
   Benefit: Captain knows if viewing live or cached/fallback
   Display: 🟢 LIVE / 🟡 FALLBACK / 🔴 STALE badges

✅ RESPONSIVE DESIGN (desktop → mobile)
   Rationale: STARFLEET COMMAND usable anywhere
   Benefit: Works on bridge (desktop) or mobile (captain's device)
   Breakpoints: 1200px (tablet) / 640px (mobile)
