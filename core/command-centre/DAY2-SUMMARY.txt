════════════════════════════════════════════════════════════════════════════════
 HOW TO USE
════════════════════════════════════════════════════════════════════════════════

Setup (5 minutes):

  1. Export Number One data:
     cd /core/coordination
     python3 number_one_exporter.py --export-sample
     # Creates: outputs/daily_brief.json, work_queue.json, escalations.json

  2. Verify files created:
     ls -la outputs/
     # Should show 3 JSON files

  3. Start backend:
     cd /command-centre/backend
     npm start
     # Server starts on http://localhost:5000

  4. Test integration:
     curl http://localhost:5000/api/v1/coordination/brief
     # Should return coordination data

Verify Fallback (optional):

  1. Delete JSON files:
     rm /core/coordination/outputs/*.json

  2. Call API again:
     curl http://localhost:5000/api/v1/coordination/brief
     # Should still work with mock fallback
     # Response includes: "dataSource": "from-mock-fallback"

Run Tests:

  npm test -- coordination-integration.test.js
  # Should show: 42 tests passing
